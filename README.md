# ワードウルフ 🐺

スマホ1台を回して遊ぶ「少数派当てゲーム（ワードウルフ）」。
インストール不要・通信不要で、ブラウザで開くだけで遊べます。

**▶ 遊ぶ: https://morishita8268-blip.github.io/word-wolf/**

## 特徴

- お題は16ジャンル264ペア。YouTuber・芸能人・スポーツ選手・時事トレンド・アニメ作品・アニメキャラ＋定番10ジャンル
- ワードは**長押し中だけ表示**。指を離すと必ず隠れるので、覗き見・消し忘れが起きません
- 議論タイマー（30秒〜5分、一時停止／＋30秒、残り5秒の警告音つき）
- 投票は「かんたん」（追放者を選ぶだけ）と「しっかり」（1人ずつ投票して自動集計・同票なら再投票）
- 結果画面のボタンで、**AI音声がウルフの名前を読み上げ**てから正体を公開
- 追放されたウルフが市民のワードを当てたら逆転勝ちになる「逆転チャンス」

## 遊び方

1. 人数・ウルフの人数・議論タイム・お題ジャンルを決めてスタート
2. スマホを回して、1人ずつ長押しで自分のワードを確認（自分がウルフかは分かりません）
3. 制限時間内に、自分のワードについてぼかして話す
4. せーの、でウルフだと思う人に投票
5. 「ウルフを発表する」で答え合わせ

ウルフを追放できたら市民の勝ち、市民を追放したらウルフの勝ちです。
